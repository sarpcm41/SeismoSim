# SeismoSim

SeismoSim is a Python based structural dynamics simulator that models how buildings respond to earthquake ground motion using numerical methods. The project focuses on SDOF systems and allows users to analyze how key structural parameters such as mass, stiffness, and damping affect a building’s dynamic response.

## Features
- Simulation of structural response under earthquake excitation
- Parameter-based analysis (mass, stiffness, damping)
- Time-history response calculation (displacement, velocity, acceleration)
- Data visualization using plots
- Modular Python structure for extensibility

## Goal
To provide an educational computational tool for understanding fundamental concepts in structural dynamics and earthquake engineering through simulation.
